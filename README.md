# Landingforyou

Рабочая локальная версия портфолио с серверной админкой.

Для запуска нужен Node.js 24 или новее. Дополнительные пакеты не требуются.

```sh
npm start
```

Сайт открывается по адресу http://127.0.0.1:4173, админка — http://127.0.0.1:4173/admin.

Учётная запись владельца настроена в локальной базе. Для создания или смены учётной записи запустите `npm run setup-admin` и введите логин и пароль. Пароль хранится в виде scrypt-хеша. Настройка учётной записи завершает действующие сеансы.

В админке можно создавать, редактировать, публиковать, скрывать и удалять проекты и услуги, менять тексты и Telegram, загружать изображения и просматривать заявки. Кнопки публикации и сохранения записывают изменения в базу. Предпросмотр показывает текущие изменения до сохранения.

SQLite хранится в `.local/portfolio.sqlite`. Сохраните всю папку `.local` при переносе сайта. Не добавляйте её в Git. `DATA_DIR` задаёт другой каталог для данных. Медиа и заявки также хранятся в базе.

Форма сохраняет заявки в админке. Уведомления через Telegram Bot API потребуют отдельного токена бота и настройки получателя. Прямая кнопка связи уже открывает диалог с владельцем в Telegram.

`HOST` и `PORT` управляют адресом сервера. По умолчанию он доступен только на этом компьютере. Для размещения на сервере с HTTPS задайте `PUBLIC_ORIGIN` равным внешнему адресу сайта. Эта настройка включает Secure для cookie сеанса.

`npm test` проверяет вход, защиту админки, публикацию, скрытие, предпросмотр, загрузку файлов, сохранение заявок, выход и сохранность данных после перезапуска на отдельной временной базе.

Исходники сайта находятся в `templates/site.html`, `public/site.css` и `public/site.js`. Сервер и работа с данными — в `src`. Ранее подготовленный файл `outputs/portfolio-extrafazant.html` теперь открывает рабочий локальный сайт.

## Размещение на Render

Репозиторий содержит Dockerfile и render.yaml для серверной версии с постоянным диском. Создайте Blueprint из репозитория, проверьте стоимость выбранного сервера и диска, затем укажите ADMIN_PASSWORD в закрытых настройках Render. Значение задаёт пароль только при первом старте пустой базы.

Render передаёт внешний HTTPS-адрес через RENDER_EXTERNAL_URL. Сервер использует его для проверки источника запросов и Secure cookie. Health check доступен по /health.

Постоянный диск хранит базу, изображения, заявки и учётную запись между развёртываниями. Папки .local, work, outputs и файлы .env исключены из репозитория и Docker-образа.
